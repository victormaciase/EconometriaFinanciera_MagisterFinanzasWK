# Econometría Financiera
Curso de fundamentos de econometría aplicados al análisis de datos financieros.

El análisis de los datos se realiza usando Python.

Los tópicos que serán cubiertos incluyen: 
1. Regresión lineal
2. Series de tiempo (modelos ARMA, ARIMA, ARCH y GARCH)
3. Modelos de variable dependiente limitada (modelos de probabilidad lineal, logit y probit)
